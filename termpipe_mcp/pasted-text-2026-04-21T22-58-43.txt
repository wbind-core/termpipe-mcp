# Zero-Deps Universal Hardware Control Platform - Final Implementation Plan

## Narrative

We are building a universal hardware control system that automatically detects the user's computer hardware and deploys appropriate control mechanisms. Rather than relying on external package managers, we clone all vendor toolkit source repositories directly and incorporate their code into our local codebase. Our existing tools `cond` (automation CLI) and `kb` (IPC message bus) provide the orchestration layer. We now add hardware detection, sensor monitoring, fan control, power management, brightness control, audio control, and vendor-specific toolkits for RGB and GPU switching.

## Phase 3: Extract and Integrate Each Repository

### 3.1 hara-hachi-bu (Power Management)

**Extract these files:**
- `lib/battery.js` - sysfs battery threshold logic
- `lib/power-profiles.js` - power-profiles-daemon DBus interface
- `lib/rule-engine.js` - auto-switching rule logic
- `resources/hhb-power-ctl` - privileged helper script

**Integrate into cond:**
- Port the battery threshold write logic to Rust (or keep as shell function called by cond)
- Create `cond --battery-mode [full|balanced|max]` - writes to `/sys/class/power_supply/BAT*/charge_control_end_threshold` (100, 80, 60 respectively)
- Create `cond --power-profile [performance|balanced|power-saver]` - calls `power-profiles-daemon` DBus API
- Port the rule engine to listen to `kb` topics (`sys.power.ac`, `sys.lid`, `sys.display.external`) and trigger profile changes

**Files to copy to cond source:**
```

cond/src/power/profiles.rs
cond/src/power/rules.rs
```

## Phase 5: Vendor Dispatcher

Create dispatcher in `cond/src/dispatcher.rs`:

```rust
fn detect_hardware() -> HardwareVendor {
    let dmi = DMI::read();
    match dmi.manufacturer.as_str() {
        "ASUS" | "ASUSTeK COMPUTER INC." => {
            if dmi.product.contains("ROG") {
                HardwareVendor::AsusRog
            } else {
                HardwareVendor::Asus
            }
        }
        "LENOVO" => {
            if dmi.product.contains("Legion") {
                HardwareVendor::LenovoLegion
            } else {
                HardwareVendor::Lenovo
            }
        }
        "System76" => HardwareVendor::System76,
        _ => HardwareVendor::Generic,
    }
}

fn load_vendor_commands(vendor: HardwareVendor) {
    match vendor {
        HardwareVendor::AsusRog => {
            // Register ASUS-specific command handlers
            register_rgb_handler(asus_rgb_handler);
            register_anime_handler(asus_anime_handler);
        }
        HardwareVendor::LenovoLegion => {
            register_fan_handler(lenovo_fan_handler);
            register_kbd_handler(lenovo_kbd_handler);
        }
        HardwareVendor::System76 => {
            register_fan_handler(system76_fan_handler);
        }
        _ => {}
    }
}
```

## Phase 7: Udev Rules for Permissions

Create `/etc/udev/rules.d/99-cond-hardware.rules`:

```bash
# Backlight permissions
SUBSYSTEM=="backlight", ACTION=="add", RUN+="/bin/chgrp video /sys/class/backlight/%k/brightness", RUN+="/bin/chmod 664 /sys/class/backlight/%k/brightness"

# LED permissions (for keyboard backlight)
SUBSYSTEM=="leds", ACTION=="add", RUN+="/bin/chgrp input /sys/class/leds/%k/brightness", RUN+="/bin/chmod 664 /sys/class/leds/%k/brightness"

# Power supply permissions (for battery thresholds)
SUBSYSTEM=="power_supply", ACTION=="add", RUN+="/bin/chgrp power /sys/class/power_supply/%K/charge_control_end_threshold", RUN+="/bin/chmod 664 /sys/class/power_supply/%K/charge_control_end_threshold"

# PWM fan permissions
SUBSYSTEM=="hwmon", ACTION=="add", RUN+="/bin/chgrp video /sys/class/hwmon/%k/pwm*", RUN+="/bin/chmod 664 /sys/class/hwmon/%k/pwm*"
```

## Phase 10: Build System

Update `Makefile` in cond root:

```makefile
.PHONY: all vendor clean install

all: vendor build

vendor:
	mkdir -p vendor
	cd vendor && \
	git clone https://github.com/wiiznokes/fan-control.git && \
	git clone https://github.com/Hummer12007/brightnessctl.git && \
	# ... (all other repos)

build:
	cargo build --release
	# Compile schemas if any
	glib-compile-schemas schemas/

install:
	install -Dm755 target/release/cond /usr/local/bin/cond
	install -Dm755 target/release/kb /usr/local/bin/kb
	install -Dm644 99-cond-hardware.rules /etc/udev/rules.d/
	# Create config directories
	mkdir -p /etc/cond /usr/share/cond
	# Copy udev rules and helper scripts
	cp -r resources/* /usr/share/cond/

clean:
	cargo clean
	rm -rf vendor
```

## Summary

1. **Clone all 10 repositories** listed in Phase 2 into `vendor/`
2. **Extract specific files** from each as listed in Phase 3
3. **Integrate extracted code** into `cond/src/` following the directory structure above
4. **Implement detection system** (Phase 4) reading DMI, USB, PCI
5. **Implement dispatcher** (Phase 5) that loads vendor-specific commands
6. **Add new CLI commands** (Phase 6) for all hardware control features
7. **Create udev rules** (Phase 7) for device permissions
8. **Set up kb topic publishing** (Phase 8) for events and sensor data
9. **Create profile system** (Phase 9) for named configurations
10. **Update Makefile** (Phase 10) to build everything

The result will be a single binary `cond` that provides unified hardware control across ASUS, Lenovo, System76, and generic laptops, with zero external dependencies at runtime.
